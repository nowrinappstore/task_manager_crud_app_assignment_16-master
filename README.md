# Task Manager CRUD App (Firebase Push + Local Notifications)

Flutter + Firebase task manager: Firebase Auth (email/password + Google),
Cloud Firestore task CRUD, FCM push notifications, local notifications for the
foreground, and tap-to-open-task.

## Features

- Sign In / Sign Up (email + password) and Google Sign-In
- Tasks stored in Cloud Firestore: `users/{uid}/tasks/{taskId}`
- Real-time Task List (Firestore stream) with search and All / Active / Done filters
- Add, edit, delete (confirmation dialog, swipe-to-delete), mark completed
- Title, description, due date + time, priority (low / medium / high), created date
- Local reminder at the due time (cancelled when the task is completed or deleted)
- FCM token saved to `users/{uid}.fcmToken` (also copyable from the app bar key icon)
- **Foreground:** FCM message received -> a local notification is shown
- **Background:** the system shows the FCM notification
- **Terminated:** `getInitialMessage()` handles the tap when the app launches
- **Tap on a notification:** returns to the Task List and opens the task whose ID
  is in the notification data (`taskId`)
- Priority-based notifications: separate Android channels for high / medium / low
  (high-priority foreground notifications get a 🔥 in the title)

## Setup

1. `flutter pub get`
2. Firebase console:
   - Authentication -> enable **Email/Password** and **Google**
   - Firestore Database -> create the database, then paste `firestore.rules`
     into the Rules tab and publish
   - Google Sign-In on Android: add your debug SHA-1 / SHA-256
     (`cd android && ./gradlew signingReport`) in Project settings and download
     the updated `google-services.json` into `android/app/`
3. `flutter run` (a real device or an emulator with Google Play services)

## Test notifications

1. Sign in, add a task, then tap the **key icon** in the app bar to copy the FCM token.
2. Copy that task's document ID from Firestore (`users/{uid}/tasks/{id}`).
3. Send a notification:
   - **Firebase console:** Messaging -> New campaign -> Notifications ->
     title `New Task`, text `You have a new task: Complete Flutter Assignment` ->
     *Send test message* with the token. Under *Additional options -> Custom data* add
     `taskId` = the task ID and `priority` = `high`.
   - **Script:**
     ```
     cd tools && npm init -y && npm install firebase-admin
     node send_test_notification.js <FCM_TOKEN> <TASK_ID> high "Complete Flutter Assignment"
     ```

| App state | What to do | Expected |
|---|---|---|
| Foreground | Keep the app open, send | A local notification appears; tapping it opens the task |
| Background | Press Home, send | System notification; tap opens the task |
| Terminated | Swipe the app away, send | System notification; tap launches the app and opens the task |

## Notes

- Messages that only have a `data` block (no `notification`) are not shown by the
  system in background/terminated state. Send a `notification` block as above.
- Never commit `tools/serviceAccountKey.json` (it is in `.gitignore`).
